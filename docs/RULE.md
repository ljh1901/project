# 1. Mandatory Rules

> 본 규칙은 AI Coding Agent(Codex 등)의 모든 코드 분석 및 수정 작업에 우선 적용합니다.
>
> **사용자의 명시적인 승인 없이 파일을 수정하지 않습니다.**

## 1-1. 파일 탐색 및 수정 범위 제한

- 사용자 요청과 직접 관련된 파일만 탐색하고 읽습니다.
- 프로젝트 전체 파일을 일괄적으로 읽거나 분석하지 않습니다.
- 전체 파일 검색이 필요한 경우 먼저 사용자에게 사유와 범위를 설명하고 승인을 받습니다.
- 관련 없는 파일은 읽거나 수정하지 않습니다.
- 기존 정상 기능, 공통 모듈, 설정 파일을 임의로 변경하지 않습니다.
- 요청 범위 밖의 리팩토링 및 코드 정리를 수행하지 않습니다.
- 필요한 파일을 찾을 수 없는 경우 임의로 탐색 범위를 확대하지 않고 사용자에게 확인합니다.

## 1-2. 수정 전 사용자 승인 필수 (Confirm Before Edit)

**모든 파일 수정은 사전에 사용자 승인을 받아야 합니다.**

AI Agent는 수정 전에 다음 정보를 제공합니다.

1. 수정 대상 파일 및 경로
2. 수정 대상 클래스 / 메서드
3. 현재 코드의 문제점
4. 변경할 코드 및 변경 이유
5. 다른 기능에 미치는 영향

가능하면 변경 전후 코드를 비교하여 설명합니다.

**[기존 코드]**

```java
if (result >= 0) {
    return true;
}
```

**[변경 예정 코드]**

```java
if (result > 0) {
    return true;
}
```

## 1-3. 승인 전 금지 사항

사용자가 승인하기 전까지 다음 작업을 수행하지 않습니다.

- 파일 생성 / 수정 / 삭제 / 이동 / 이름 변경
- 코드 자동 수정 및 리팩토링
- Import 자동 정리
- Dependency 및 설정 변경
- Database Schema 변경
- 코드 포맷팅으로 인한 파일 변경
- Git Commit / Push

읽기 전용 분석과 변경 방안 제시는 가능합니다.

## 1-4. 승인 후 작업 범위

- 승인받은 파일과 코드 범위만 수정합니다.
- 승인받지 않은 추가 변경이 필요하면 작업을 중단하고 다시 확인받습니다.
- 승인 후에도 기존 기능과 프로젝트 규칙을 유지합니다.
- 수정 완료 후 변경 파일, 변경 내용, 검증 결과를 보고합니다.
- 승인받은 범위 외의 파일은 변경하지 않습니다.

## 1-5. 예외
사용자가 특정 작업에 대해 명시적으로 사전 승인을 생략하도록 지시한 경우에는 해당 작업에 한해 승인 절차를 생략할 수 있습니다.
